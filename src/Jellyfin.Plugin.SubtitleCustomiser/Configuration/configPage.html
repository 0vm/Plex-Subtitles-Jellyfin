Plex Subtitles Jellyfin

Clicking the subtitles (CC) button in the web player opens a Plex style panel for the subtitle track, colour, position, size, style and offset. Each user's choices are saved in their browser. The values below are what users start with until they change them.

When off, the web player keeps Jellyfin's standard subtitle menu and rendering. Browsers pick up the change on their next page load.
While the control bar is showing, bottom subtitles rise so the bar does not cover them.
